# 本地可视化工作台

流程：**WeFlow 提取 → 本地校验与上下文分析 → 人工整理资料 → 手动接入小智**。

## 启动

需要 Python 3.10+ 和现代浏览器。运行环境只有 Python 标准库；前端为原生 JavaScript、HTML、CSS，不需要 npm install。Node.js 18+ 仅用于前端状态测试。

在仓库根目录运行 `python -B -X utf8 scripts/local_app.py`，再打开 `http://127.0.0.1:8765`。Windows 可双击根目录 `start-local.cmd`。终端需保持运行，Ctrl+C 停止；端口占用时使用 `--port 8766`，并打开新端口地址。请勿直接双击 web/index.html，它依赖本机接口。

只监听 127.0.0.1，不面向局域网或公网。请求检查 Host、Origin、随机会话令牌；不开放任意本地文件读取接口。静态资源全部来自仓库，没有 CDN、遥测或远程模型请求。不要用端口转发将它发布为公网服务。

## 1. 导入

可先点「试用虚构示例」体验 4 条虚构消息。真实数据的提取仍由外部 WeFlow 完成，见 [接入说明](weflow-integration.md)。本工具不安装 WeFlow、不读取微信数据库、不获取密钥。

| 格式 | 接收范围 | 顺序与限制 |
|---|---|---|
| WeFlow | 保存的原始 `/api/v1/messages` 成功响应 | 分页文件按名称升序，请用 001、002 等补零编号；必须填写独立核对的预期总数 |
| JSONL | 本项目消息字段，每行一个对象 | 按文件名升序读取，保留原有记录顺序，检查乱序，不自动修正 |
| JSON | 符合本项目字段的消息对象数组 | 不自动猜测第三方导出字段，保留数组顺序 |
| ZIP | 任意子目录中的 `messages_*.jsonl` | 按归档路径排序；其他文件列入排除清单，不解析、不解压到磁盘 |

总输入最大 32 MiB，最多 100 个输入文件、100000 条主会话。ZIP 最多 1000 条目，声明的总展开大小不能超过 32 MiB。不能据此声称所有 WeFlow 导出格式均兼容；HTML、CSV、DB、SQLite 不在本页支持范围内。较大档案使用现有命令行工具。

JSON/JSONL 只接受唯一键及合法 JSON 常量。转发内嵌记录独立保存，直接选入 forwarded 文件或带父消息索引的记录会拒绝导入。WeFlow 导入器检查单私聊、分页结束标记、数量和发送方向；相同时间保留输入顺序，不执行未知 JavaScript。

## 2. 校验与阅读上下文

统计总量、发送方、北京时间跨度、月度分布、消息类型、附件标记；检查字段、时间、序号连续性、完全重复记录、预期总量。相同时间/发送者/类型/正文/引用的组合另列为重复候选，不自动删除。附件未知资源、缺失引用快照单独计数。

报告可下载为 `chat_audit.local.json`，含输入 SHA-256、异常、排除文件及隐私模式命中数量。检测不是完整脱敏证明，未提供预期总数或源文件本身有缺失时，无法证明历史完整。

按正文/引用搜索或发送者定位，显示命中消息前后各 3 条，不改正文，不隐藏相邻系统事件。没有自动情感分类或关系结论；需要阅读完整相关上下文并按 [分析方法](analysis-methodology.md) 记录观察。不会调用云端模型做深度分析。

## 3. 资料与记忆

支持人格、用户、事件、关系背景、短期上下文五类候选。每条包含 ID、来源、时间、可信状态及确认状态。用户逐条确认后才能加入角色背景；修改后撤销确认。导入也恢复为候选，不将文件自带的确认标志直接当作本次授权。

导出使用 [memory_schema.json](../xiaoyu/memory/memory_schema.json) 的 1.0 envelope：`dataset_id`、`records`、来源对象、revision 等字段。编辑和确认变更增加 revision。重新导入保留 ID，拒绝重复 ID 和过期项。工作台只编辑 summary，不编辑 tags 或完整后端元数据，因此不是通用无损记忆档案编辑器。被删除项从本页移除，下次导出不包含；不会删除此前下载的副本，也不会向外部服务传播删除。

短期上下文创建时有效期为 24 小时，始终不加入长期角色背景。候选箱在浏览器内存中，刷新前需手动导出；无 localStorage、IndexedDB 或后台文件保存。下载文件中可能含私人背景，请自行放在私有目录。仓库忽略 `*.local.*`；公开仓库不应包含真实记忆。

## 4. 生成并手动配置小智

选择完整/精简/语音短版人格，填写通用风格。复核个人背景与第三方隐私后勾选确认，生成仅包含已确认非短期记忆的提示词。追加背景作为 JSON 资料附在原有人格规则之后，不把聊天正文自动拼入提示词。

复制或下载 `xiaoyu_prompt.local.txt` 后，按 [小鱼使用指南](../xiaoyu/README.md) 手动保存到官方控制台。粘贴会把选定资料发送给云端，请先复核。本工具不操作云端账号，不声称自定义记忆 JSON 已接入服务端。长期记忆检索、对话自动写回和跨设备同步仍需后端实现及接入验证。

## 验证

```powershell
python -B -m unittest discover -s tests -v
node --test tests/test_workspace_ui.cjs
```

测试只用虚构样例。覆盖四种导入、数量/重复/乱序、转发隔离、本机请求限制及候选确认、修改失效、记忆往返、短期上下文与文本安全渲染。
