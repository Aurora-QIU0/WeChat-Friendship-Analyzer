# 消息格式与统计口径

文件采用 UTF-8 JSONL，一行一个 JSON 对象。建议按北京时间月份拆分。

| 字段 | 约定 |
|---|---|
| `timestamp` | 正整数，原始 Unix 秒。 |
| `datetime` | 与时间戳对应的 ISO 8601 北京时间，格式如 `2025-01-01T12:00:00+08:00`。 |
| `sender` | 主会话用稳定的发送者标签。系统事件用「系统」。身份未经核实的转发内嵌记录用 null。 |
| `message_type` | 保留源类型标签，例如 `text`、`quote`、`image`、`system`。 |
| `content` | 保留原档案显示文字。媒体占位符也作为文字保留。 |
| `quote_content` | 已知的引用文字，无可用内容时用 null。 |
| `has_attachment` | 布尔值。附件细类和可用状态按需用可选字段记录。 |

主会话按时间戳升序排列，同秒保留源顺序。若提供 `message_index`，在一起处理的文件范围内应连续。系统事件留在总量中，计算双方发送量时单列。合并转发的外层卡片算作主会话一条消息，内嵌消息另存。引用正文供理解上下文，计数以外层消息为准。

可选字段见 [JSON Schema](../templates/message_schema.json)。脚本检查核心字段和时间一致性。对于没有稳定序号的输入，完全相同的行会被标为重复候选，需回查来源。
