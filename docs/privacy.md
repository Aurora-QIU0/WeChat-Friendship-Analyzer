# 隐私与本地处理

只处理有权使用的数据。真实对话、数据库、图片、音视频、压缩包和分析报告放在忽略目录内。公开示例使用虚构内容。

`anonymize_data.py` 生成独立副本，只保留允许字段，可按显式映射替换发送者标签。正文和引用文字逐字保留。脚本发现可疑模式时停止写出，便于你先核对。转发显示名同样属于私人数据，可通过显式别名处理。

扫描可提示常见微信 ID、Windows 绝对路径、部分凭据形式和可能的中国大陆手机号。真实姓名、地址、生活细节和隐含身份仍需人工检查。统计报告也可能暴露身份或活动模式。

本骨架的 Python 命令在本机运行，不发起网络请求。若另行将内容提交给 AI 或第三方服务，先确认发送范围、隐私设置和参与者的分享权限。不要把真实数据提交到公开仓库。
