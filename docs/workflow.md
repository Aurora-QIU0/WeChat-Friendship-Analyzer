# 从 WeFlow 到小智的完整工作流

**WeFlow 提取 → 数据整理与分析 → 整合人物资料 → 接入小智。**

## 1. 用 WeFlow 在本地取得聊天记录

确定已经获授权的指定好友和时间范围，在外部 WeFlow 环境完成读取与提取。当前上游可能要求另行配置原生组件，步骤与许可见 [WeFlow 接入说明](weflow-integration.md)。本项目不自动安装或执行这些组件。

将原始 `/api/v1/messages` JSON 分页保存到本机 `private_data/`，从第一页持续取得最后一页。独立核对预期消息数，再用 [import_weflow.py](../scripts/import_weflow.py) 转换。该脚本仅支持文档约定的响应结构，不能把所有 WeFlow 导出格式都当作兼容输入。

已有规范 JSONL 可从下一步开始。其他 HTML/JS 分片需要独立适配：先识别静态数据包装，再安全解析，不执行未知脚本。

## 2. 先校验数据，再分析内容

运行 `validate_jsonl.py --check-privacy` 和 `audit_data.py`，核对主消息总量、双方数量、系统事件、月度分布、首尾时间与附件情况。检查异常并追溯原始导出，不擅自去重或删消息。完整性不过关时，应先解决数据问题再做结论。

按 [分析方法](analysis-methodology.md) 与 [分析提示词](../templates/analysis_prompt.md) 结合前后话轮分析交流习惯、主动性和变化。事实、推测与未知分别记录；普通关心不能直接作为爱情证据。现有脚本负责数据检查，不会自动完成这些语义判断。

原始记录与私人报告保存在本地。若决定使用云端模型分析私人内容，须另行确认接收服务和允许发送的范围；这条流程本身不授予上传原文的权限。

## 3. 整合为小智可用的人物资料

用 [小鱼目录](../xiaoyu/README.md) 的通用资料作模板，人工审阅并整理：

- 人格：独立 AI 身份、稳定性格与互动边界。
- 风格：短句、接话、幽默分寸及情境切换；提炼模式，不复制私人原句、称呼和经历。
- 示例：原创的日常、情绪支持、玩笑和技术对话。
- 用户背景：仅纳入主动确认且接入所必需的信息，注明来源与更新时间。
- 私人记忆：按 [记忆规则](../xiaoyu/memory/memory_rules.md) 维护，不把推测或第三方隐私自动存为事实。

这一步产物是审核过的提示词和背景资料，不是把整个聊天档案放进云端知识库。人格资料与私人记忆分开保存，公开 GitHub 只放通用模板和虚构示例。

## 4. 接入小智并验证

按 [快速使用](../xiaoyu/README.md#快速使用)，先备份现有角色介绍，再手动复制一版提示词到官方控制台对应智能体。固定背景只加入已确认且允许提交至该云端服务的信息。保存后按实际提示重启或开启新对话，检查身份、语气、技术回答与背景使用情况。

官方记忆以账户实际能力为准。本项目 JSON 是自定义资料结构，不能承诺可直接导入官方记忆数据库；固定背景也不等于自动更新的长期记忆。自定义记忆后端尚未实现。本流程不要求改 GPIO 或重新烧录。

## 可选交付与统计边界

需要归档或交付分析数据时，用 `anonymize_data.py` 创建显式别名副本，再用 `package_data.py` 打包、试解压并核对 SHA-256。原文件不改动，打包文件不会自动上传。主会话使用默认 `--scope main`，已单独提取的转发内嵌记录使用 `--scope forwarded`，不得混入双方统计。当前 WeFlow 转换器保留主消息但不展开转发，也不重建缺失附件或跨消息引用链。
