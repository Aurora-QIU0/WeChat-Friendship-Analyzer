# 本地工作流

1. 确定已获授权的单聊和时间范围，使用现有的可读导出。确认源文件可以只读访问，私人输入放在 `private_data/`。
2. 若导出为 HTML 和脚本分片，先识别固定的数据包装，再用 JSON 解析器提取数据。执行页面脚本不属于提取步骤。保留主消息、引用文字和必要顺序，将合并转发的内嵌消息另存。
3. 用 `audit_data.py` 生成月度、双方、系统和附件统计。和源导出的数量、首尾时间对照。若发现异常，先追溯源记录。
4. 用 `validate_jsonl.py --check-privacy` 检查结构和已知隐私模式。需要整理字段或换用发送者别名时，用 `anonymize_data.py` 生成独立副本。
5. 用 `package_data.py` 打包审核通过的副本。保留脚本输出的摘要并在本地试解压。使用多个输入时，按月份或时间顺序传参。
6. 选择适当的分析范围并确认隐私设置后，使用分析提示词开展证据分析。

`audit_data.py` 和 `validate_jsonl.py` 默认检查主会话。对转发内嵌记录使用 `--scope forwarded`。主会话和转发分别统计。
