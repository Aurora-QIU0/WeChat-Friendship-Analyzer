# 互动与关系分析口径

先确认时间覆盖、双方消息数量、系统事件、附件缺失和转发边界，再描述互动。月度比较同时报告消息数和活跃天数。末月未覆盖完整月份时注明截止日。

| 指标 | 计算或证据口径 |
|---|---|
| 发起交流 | 设定无消息间隔后，把下一条双方消息视为会话开端。报告阈值并对不同阈值做敏感性核对。 |
| 延续交流 | 检查双方是否接住话题、追问或隔天继续。同一人连发多条时结合上下文看。 |
| 回复节奏 | 描述同一会话中切换发送方的间隔。它可能受作息、线下活动、平台或聊天习惯影响。 |
| 关心、支持与信任 | 引用可观察到的倾听、帮助、兑现承诺和对脆弱表达的回应，并注明上下文。 |
| 关系变化 | 分开描述时间上的共现与当事人明确说出的原因。记录能解释变化的其他因素。 |
| 恋爱可能性 | 分开检查友情、特殊关注、单向试探、双向好感和明确表达。主动寻找支持证据和反向证据。 |

报告中的例证用时间和消息序号定位。对每个判断说明观察到的行为、可能的解释和仍未知的信息。附件占位、转发显示名和片段引用只能支持有限结论。未来建议应尊重对方边界，并以真实沟通为主。
